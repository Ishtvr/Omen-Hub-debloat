# Omen Hub++ 0.10.0-beta.8

- A value that does not stick no longer fails the preset. It is skipped, named in
  the status line and returned to its original; every other value stays applied.
  This now also holds when the firmware takes a value back after it was confirmed,
  for presets with a linked fan curve, and when an HP mode/firmware step does not
  confirm (named as "not confirmed" instead of aborting).
- Fast limit (PPT) in Unleashed (Dynamic Boost): the 8E35 firmware keeps PPT at
  80 W there. The preset skips PPT without writing and says so; Keep preset no
  longer rewrites it endlessly. Slow limit, Tctl and Curve Optimizer are unchanged.
- Saving a preset with "apply at sign-in" no longer shows a blocking failure when
  one value was skipped. A value at its captured original does not block sign-in
  approval; at least one value must be confirmed. A later failure keeps the saved
  preset and reports what was not applied or not set up.
- The status line separates confirmed, partially applied, requested without
  readback (HP mode, TPP, fan curve) and values replaced by a precedence rule.
- Keep preset is event driven: resume, AC/DC, display on and power-plan changes
  trigger one debounced check (500 ms). Checks run every 5 s for a minute after a
  trigger, otherwise every 30 s. A value overwritten after three rewrites is given
  up until the next Apply. Only an Apply from the current Windows boot is held.
- Boot-time apply keeps the sign-in approval when a firmware step or value fails
  after the device/binding checks.
- GPU curve editor: points are picked within 15 px; dragging a point inside the
  selected band moves the band as a group; Shift + drag on free space selects a
  range; click on free space or double-click clears it; Escape cancels a drag
  without history; Enter edits the value, Enter in the value field applies it;
  Shift + Enter flattens; Ctrl + D restores the loaded curve; Ctrl + S takes the
  curve over; Ctrl + 0 fits; +/− and the wheel zoom (Ctrl: Y axis, Shift or a
  sideways swipe: pan); F1 shows the shortcuts; a readout follows the dragged point.

This release adds software validation, not a new hardware write or lifecycle
qualification. See [Validation](../VALIDATION.md).
