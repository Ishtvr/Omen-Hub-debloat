# Omen Hub++ 0.10.0-beta.13

- Fan curve: a click on free chart space adds a point there, and a double-click
  on a point removes it. Since beta.12 removed the +/− buttons, points could
  only be added by double-click and removed only with the Delete key.
- GPU curve: Shift + drag and Shift + Up/Down now offset the curve using the
  shape of the NVIDIA driver default curve, the thin line in the chart. Before,
  they used the curve loaded when the editor opened, so after Ctrl + R (reset to
  the NVIDIA default) the old preset curve came back with the first Shift edit.
  Ctrl + D still restores the curve from opening.
- The legacy native GPU curve window draws the NVIDIA driver default curve as
  its reference line, matching the Shift offset.

Software and UI validation only. See [Validation](../VALIDATION.md).
