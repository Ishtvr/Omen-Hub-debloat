# Omen Hub++ 0.9.0-dev.3

Local development build, 29 October 2026. This is not a new public beta release or hardware qualification.

- Integrates localization commit `2efca79` with the preserved local curve optimizations and Intel retirement.
- Batches native preset layout changes, discards stale copied control pixels, and keeps themed drawing in the paint path.
- Adds persistent application settings for language, app startup, tray startup and closing behavior. Preset sign-in authorization remains separate.
- Removes Max-Fan from the preset editor; explicit Save retires legacy preset entries while retaining the independent fan and recovery contracts.
- Shows concrete preflight conflicts, widens choice fields, centers the native name edit and supports Ctrl+A with native Undo.

The desktop shortcut opens the tested `dist/Omen Hub++.exe` with `--show`. The protected installation, running fan helper, services and existing preset sign-in approval are not upgraded by this local distribution update.

The 85 °C preset target is distinct from a live limit readback and measured Tctl. The read-only diagnostic on 29 October found a 95 °C programmed limit while the conflicted preset had not applied. No hardware setting was changed by this update. Full controller independence, long-term limit persistence and complete DPI/power-lifecycle acceptance remain pending.

See [Validation](../VALIDATION.md) for checks and artifact identity, and [Hardware support](../HARDWARE_MATRIX.md) for current limits. The distribution's `build-info.json` records the source base, dirty working-tree state and executable SHA-256.
