# Omen Hub++ 0.10.0-beta.16

## New in 0.10.0-beta.16

- **Flashless GPU Dynamic Boost Limit (GPU TGP, 115–135 W default)**: Reversible driver-registry VBIOS `Policy[2]` override for HP 8E35 / BIOS F.13 / RTX 5070 Laptop GPU (`vbios_tgp.rs`), with native `cfgmgr32.dll` dGPU restart and NVML readback verification — no EEPROM flashing, no Secure Boot change, and no Windows Defender exclusions. Restoring the preset or switching to a stock HP mode restores factory 115 W.
- **Custom Dynamic Boost max wattage setting (Settings -> General)**: Configurable upper bound (`115–175 W`, default `135 W`) persisted in `gpu-tgp-settings.json` (keeping `app-settings.json` backwards-compatible with older protected helpers), with live validation, live Preset slider range update, and a clear thermal/VRM/PSU warning above the verified 135 W range.
- **Reversible NVPCF Sub-function #9 PPT unlock (`nvpcf_ppt.rs`)**: Allows custom CPU Fast PPT and Slow PPT (`15–80 W`) limits to hold cleanly while Dynamic Boost (Unleashed) remains active; restored automatically on preset restore or stock HP mode switch.
- **dGPU restart crash protection**: All GPU telemetry and preset-hold NVML probes run in disposable child processes (`gpu-telemetry-read`, `gpu-limit-read`) and yield to `ControlLease::acquire_background()` during a foreground dGPU restart, preventing `nvml.dll` access violations in the main UI process.
- **Preset info box layout**: Expanded field explanations render inside a bordered surface card below the pinned control row with explicit width calculation so text never overlaps controls or neighbouring rows.
- **Built on `main` (`0.10.0-beta.15`)**: Includes per-preset automatic battery behavior (`Verhalten im Akkubetrieb` / `battery-presets.json`), dGPU battery sleep protection (`dgpu.rs` PnP `D3cold` detection, paused GPU telemetry on battery/asleep dGPU, 30 s cool fan-helper cadence, 60 s battery hold interval), and sign-in support for presets with linked fan curves.

## Verification

- `cargo test --workspace` passing (core, platform, app, i18n DE/EN parity, guardian process).
- Live Slint UI inspection covering Overview/Presets (battery selector, Dynamic Boost limit slider, expanded info cards) and Settings (custom max Dynamic Boost limit input + warning).
- Hardware-verified on HP OMEN 16 (8E35 / BIOS F.13 / Ryzen 9 8940HX / RTX 5070 Laptop GPU, Windows Defender enabled, Secure Boot ON): 115 -> 125 -> 135 W NVML & HWiNFO64 confirmed, NVPCF Fast/Slow PPT bypass confirmed with Dynamic Boost active.
