# Omen Hub++ 0.10.0-beta.10

- New preset group **Dynamic Boost and CPU power**: Dynamic Boost, cTGP, TPP and
  the CPU power value (Slow limit, written as firmware PL1 with Dynamic Boost)
  sit together, as in the OMEN Hub's Unleashed panel.
- TPP and CPU power are sliders with the Hub's own ranges for this model
  (OMEN Hub 1101.2611.2.0, 8E35): TPP 55–72 W; CPU power 45–80 W in 1-W steps
  with Dynamic Boost, otherwise 15–160 W. The current value is shown beside the
  slider; older values outside the range are kept until the slider is moved.
- A new TPP field starts at the Hub's Unleashed budget of 72 W.

Write paths are unchanged (PL1 via HP 0x29 with PM-table readback, TPP without
readback). See [Validation](../VALIDATION.md).
