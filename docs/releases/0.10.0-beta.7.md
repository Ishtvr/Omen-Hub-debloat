# Omen Hub++ 0.10.0-beta.7

- Select a GPU voltage range by dragging or entering its bounds, select all/to-end,
  and equalize the selected frequency targets in one undoable edit. Empty ranges
  cannot accidentally flatten the remaining curve. Driver anchors stay fixed.
- Cancel editing restores the current preset's saved name, values, GPU curve and
  linked fan snapshot. Reset to defaults remains a separate action.
- Save named fan presets under Cooling and attach a curve snapshot to a performance
  preset. Library editing/deletion never rewrites those snapshots. Applying a linked
  preset verifies the direct controls, then requests the shared cooling policy from
  the existing installed helper; no helper replacement is part of this operation.
- Center the bounded work areas, align common fields vertically and fit the long
  HP OMEN Cap restore action inside its button. Compact footer actions wrap.
- Enlarge the keyboard to fill the lighting work area and restore independent
  WASD, left, middle and right/numpad zones. Remove the explanatory body paragraphs;
  retain compact draft feedback and readback information through accessibility.

Linked cooling curves **cannot gain sign-in authorization**. The current helper has no curve-digest
acknowledgement: a saved request is not verified physical fan uptake or BIOS
ownership. Exact original preference files, interrupted-operation journals and
previous-owner recovery are retained. Sign-in grants are not silently enabled or
reapproved. Other hardware/range checks, existing profile data and protected helpers
are preserved.

This release adds software/UI validation, not a new hardware write or lifecycle
qualification. Full HP-independent cooling and sustained temperature-limit behavior
remain unqualified. See [Validation](../VALIDATION.md) for checks and build identity.
