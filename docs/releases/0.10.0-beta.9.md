# Omen Hub++ 0.10.0-beta.9

- Automatic battery switch rebuilt as a level-based AC/DC state machine: a check
  at app start, 750 ms after the last power event and after every resume (a plug
  change during sleep is caught). The saved AC choice, the active automatic switch
  and a manual override on battery persist in `power-switch.json`.
- A manual choice on battery blocks the automatic switch until the charger
  returns; then the saved AC choice is restored.
- Returning to AC first restores the automatic battery preset's own journal
  (Windows policies, refresh rate, CPU limits) without revoking a sign-in
  approval, then applies the AC choice.
- Automatic switches use the same latest-intent queue as Apply. A waiting or
  running manual choice always wins; the switch waits for a later check.
- New "Battery optimized" choice creates a template preset on Save: Dynamic
  Boost off (Balanced mode), Balanced plan with the efficiency power mode, boost
  mode Efficient Enabled, EPP 70 %, 60 Hz, Slow/STAPM 18 W, fast limit 30 W.
- The refresh-rate control now addresses only the internal panel; external
  monitors are untouched, and an inactive panel is reported instead of changed.
- Apply order: HP mode, 400 ms settle, Windows plan and policies, refresh rate,
  SMU limits.
- On battery, dashboard GPU telemetry and the keep-preset mode probe pause so
  NVML does not wake a sleeping dGPU.

Software validation only; battery-time behavior is not yet measured on the
device. See [Validation](../VALIDATION.md).
