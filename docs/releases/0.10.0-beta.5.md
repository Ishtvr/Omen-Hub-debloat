# Omen Hub++ 0.10.0-beta.5

- Fixed GPU curve opening when its checkbox is enabled before the first edit.
  The empty new-field placeholder previously failed the complete V/F target
  validation and produced a misleading anchor/order error instead of opening.
- The editor now initializes that empty UI placeholder from the driver's factory
  curve. Nonempty saved targets retain complete grid and driver-range validation.
  Curve changes become a preset draft through Use curve; hardware writes still
  require explicit profile application.
- Added a regression for checked-before-opening, edits, Back/reopen, Undo/Redo
  and draft acceptance in DE/EN with both renderers. A unit regression separates
  factory initialization from an applied curve, preserves saved targets and
  rejects incomplete nonempty targets.

See [Validation](../VALIDATION.md) for build identity and checks. No hardware SET
trial or additional device/lifecycle qualification was performed.
