# Omen Hub++ 0.10.0-beta.15

- A preset with a linked fan preset can now be the sign-in preset. Saving
  such a preset with **Apply this preset at sign-in** was refused with
  "Profile sign-in is not yet enabled for linked fan curves". The sign-in task
  applies the preset's other values and requests the curve from the fan
  helper, the same way **Apply** does. If the helper cannot take the request
  at sign-in, the other values are still applied and the result file names
  the reason.
- Only a fan curve the helper cannot take (CPU and GPU curves that differ)
  still blocks sign-in, with a message that says what to do.
- The sign-in check box is no longer locked while a fan preset is linked.

Everything from [beta.14](0.10.0-beta.14.md) is included. Software and UI
validation only; sign-in with a linked curve is not yet tested across a real
reboot. See [Validation](../VALIDATION.md).
