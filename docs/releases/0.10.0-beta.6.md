# Omen Hub++ 0.10.0-beta.6

- Creating a new preset with + or the New preset selector entry now immediately
  opens a fresh driver-factory GPU curve. It inherits neither an applied driver
  offset nor a previous profile's curve, cached draft or Undo history.
- Cancel preserves the old draft; Save/Discard followed by New uses the same
  initialization. Loading an existing preset keeps its saved curve. Startup
  continues to show Overview without automatically opening an editor.
- The graph receives keyboard focus after selector/prompt completion, so its
  arrow and Undo shortcuts work immediately.

Resetting the new curve affects the preview only. Use curve stages it in the
preset; explicit profile Apply remains the hardware-write boundary. Profiles,
recovery images, startup approvals and device/range validation are retained.
See [Validation](../VALIDATION.md) for exact build identity and test scope.
