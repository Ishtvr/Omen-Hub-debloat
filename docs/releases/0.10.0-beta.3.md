# Omen Hub++ 0.10.0-beta.3

- Fixed shared dimensions for ordinary form fields and matched text/icon action sizes.
  Preset selector/name align with the value column; curve tools reflow into bounded
  rows so the chart and primary action fit the compact window.
- Visual palette previews replace the theme-name dropdown. App and keyboard colors
  use one staged HSV/HEX chooser with before/selection previews, sixteen swatches,
  pointer/keyboard editing, visible focus, acceptance and cancellation.
- The keyboard brightness editor uses one common field boundary. Color acceptance
  changes the draft; firmware still requires the existing explicit guarded Apply.
- Software redraw pacing retains the display's fractional refresh period instead
  of the 144 Hz → 6 ms truncation. Coalesced timer wakes round upward, preserve phase
  and stop when idle/hidden. GPU pacing is unchanged.

See [Validation](../VALIDATION.md) for measured scope and checks. Frame counters and
WM_NULL response samples are not direct presentation-latency measurements or proof
that every scrolling workload is free of jank. Foreground CPU was also recorded;
no unmeasured CPU reduction is claimed.

Profiles, recovery, startup approval, helper ownership and hardware contracts remain.
This UI change adds no firmware-brightness opcode, hardware tuning trial or new
HP-independent lifecycle/85 °C qualification. Normal releases omit developer MCP.
