# Omen Hub++ 0.10.0-beta.12

- Curve editor (from the curve-page work): grid lines and labels on round values,
  reference line and offsets against the NVIDIA driver default curve, hover
  readout, a tidier layout without the button rows under the chart, and a round
  **i** button (and F1) listing the mouse and keyboard controls. Enter in the
  value field sets the point or, with a GPU selection, the whole selection;
  Ctrl + R resets to the NVIDIA default.
- Preset editor: the TPP and CPU power sliders keep the editor's footprint, so
  labels no longer collapse in compact windows (seen at 200 % scaling). GPU,
  Dynamic Boost and the CPU limit groups open by default.
- `.impeccable/` is now local and ignored by Git; the files stay on disk.
- `scripts/test-slint-ui.py` knows the regrouped preset fields, checks the CPU
  power slider ranges and no longer depends on toast timing.

Software and UI validation only. See [Validation](../VALIDATION.md).
