# Omen Hub++ 0.9.0-beta.3 — prerelease

This prerelease improves responsiveness and makes preset confirmation more reliable. It includes the accumulated native UI, curve, localization, installer, battery and controller changes since `2efca79`.

## Downloads

- **Setup.exe:** interactive Windows x64 installer.
- **x64.zip:** the same application with install scripts, documentation and required third-party notices/source.
- **SHA256SUMS.txt:** checksums for the application, ZIP and installer. Checksums establish file identity, not a publisher signature.

The runtime stays native and offline. CPU hardware access requires the separately installed, verified PawnIO driver. This is an experimental prerelease for the documented HP 8E35 / F.13 / Ryzen 9 8940HX / RTX 5070 Laptop configuration.

## Changes

- Windows process priority **High**, verified on startup; no realtime scheduling.
- Manual dashboard controls use their own worker and take precedence over background preset keeping. Slow telemetry no longer sits ahead of a manual Apply.
- Startup reads display preferences locally; legacy-startup migration runs off the window thread. A desktop launch with `--show` opens the dashboard despite a saved tray-start preference.
- Preset keeping rechecks the active revision under its hardware lease and only keeps settings confirmed by Apply. An old or skipped target cannot overwrite the new preset.
- Complete current-preset verification, a final read-only check after corrective writes, explicit partial-Apply feedback and unconfirmed TPP feedback.
- Pending recovery and preflight checks precede the HP mode/shared-budget prelude. The prelude's missing exact readback/restore contract remains a limitation.

Also includes central language/startup/tray settings, Intel tuning retirement with legacy-file preservation, native scrolling/redraw repairs, curve editor improvements, separate fan controls and the existing optional battery-preset/hold settings.

## Validation and limits

Formatting, **295 unit tests** (152 Core / 86 Platform / 57 App), **14 Guardian process scenarios**, Clippy with warnings denied and the Windows x64 release build passed. One manual timing benchmark remains ignored. The tested application SHA-256 is `B00BC0B101D9F6F82F5B35587EA952DDB48D3F0989A77205852FDCA87A2E9639`.

A real desktop shortcut launch opened a responding dashboard in approximately one second in a single warm-start observation. Further interactive scrolling/resize acceptance was stopped by the user. The total 50 MB tray-idle budget has not been accepted for this build.

Software checks, deployment hashes and the short read-only 65 W / 80 W / 85 °C observation are documented in VALIDATION.md. The reported historical 1,700 MHz event was not reproduced. This release does not raise saved CPU power limits or establish full independent HP replacement, sustained load stability or a completed reboot/sleep lifecycle.

Existing protected sign-in approvals and active fan helpers are distinct installations. Updating a local desktop shortcut does not update those helpers or grant a new preset approval. Preserve profiles and recovery data and follow RECOVERY.md before installing over an active controller.
