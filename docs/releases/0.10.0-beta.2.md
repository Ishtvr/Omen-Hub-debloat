# Omen Hub++ 0.10.0-beta.2

This prerelease corrects the Slint graph rendering, combines monitoring and preset
editing on Overview, and introduces consistent controls and configurable palettes.

- GPU and fan curves now use connected paths. Rotated rectangles had produced
  horizontal fragments in the normal software renderer. Axis labels, references,
  selection and point editing share a consistent plot; successful loading clears
  the loading status.
- Overview contains the selected preset's editable settings. Equal navigation targets,
  36 px controls, aligned input/value columns and wrapped choice lists replace the
  mismatched highlight/focus geometry and inconsistent fields.
- Slate, Graphite, Vesper, Light and custom background/text/accent colors preview
  immediately and persist on Save, with format/contrast guidance. A separate UI
  settings file preserves compatibility with older protected helpers.
- Lighting shows an original schematic QWERTZ/QWERTY keyboard. WASD, Rest and NUM
  pad/right groups offer color, RGB-value brightness, reset and explicit draft Apply.
  Vendor zone order is corrected; saved profiles/recovery images are not reordered.
  The right hardware zone includes adjacent keys, and the diagram is not per-key RGB.
- Slider value ownership keeps pointer/keyboard/numeric brightness edits synchronized.
  Unsaved lighting joins the existing draft/exit protection. App startup and preset
  sign-in authorization remain distinct.

Real interaction tests cover both languages/renderers, true compact geometry with
Slint scale overrides, rapid scrolling, resize, minimize/tray restoration, focus/Undo,
curve midpoint pixels, lighting drafts and a real isolated-settings process restart.
See [Validation](../VALIDATION.md) for counts, hashes, resource measurements and scope.

No new voltage/power/lighting write trial or controller-lifecycle qualification is
implied. The UI brightness control transforms already qualified RGB bytes; firmware
master-brightness bytes, exact physical zone boundaries, animations and per-key RGB
remain unqualified. Full HP-independent operation and sustained 85 °C enforcement
still require device evidence. Active installed helpers and startup approvals are
preserved during the portable build update.
