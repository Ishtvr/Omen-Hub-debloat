# Omen Hub++ Beta 0.9.0 — withdrawn

**Historical release notes.** GitHub release/tag name: `v0.9.0-beta.1`. Published 26 October 2026; the release and download assets were later deleted at the owner's request. The source tag remains for traceability. These are not download instructions for a currently available release. Current status: [Development status](../UNLOCKED_STATUS.md).

## Historical package

The Windows x64 beta included the native dashboard/tray, GPU core/VRAM offsets and V/F editor, supported CPU/Windows presets, separate fan helper, four-zone static lighting and guarded installation/sign-in tooling. Features were limited to the exact reference configuration and documented evidence.

Source tag commit: **8ebb5ecf48baf4e1ce40c72166d6e1d63e0184b9**. Executable: **3,098,624 bytes**, SHA-256 **FE10C11232E83B0527193F8D9F179584D0736D613AA0B6CCD7443CE31021571A**. The executable was not Authenticode signed. A checksum was an integrity record, not a publisher signature.

## Checks recorded then

226 Rust unit tests, 14 process/file scenarios, 60 isolated installer guard cases, formatting, Clippy and release compilation passed. Package inspection covered exact version/source identity, required notices/source, expected files and rejection of stale/dirty payloads. A parallel Windows test-directory collision was fixed before final publication.

These checks did not establish full HP-service replacement, true reboot/sleep recovery, stable arbitrary tuning, broad device support or a freely adjustable GPU TGP. The later public power-limit development and TGP investigation are separate source work, not additions to this withdrawn binary.
