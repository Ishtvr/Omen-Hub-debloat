# Omen Hub++ 0.10.0-beta.1

This prerelease replaces the normal Win32/GDI controls with a native **Rust/Slint 1.18.1** interface. Overview, Presets, Cooling, Lighting and Settings share one shell; the existing hardware engine and persistent file schemas remain.

## Changes

- Retained layout/clipping replaces moving native child controls during scroll and resize. The bounded preset form stays mounted to preserve text selection and Undo through scrolling/group collapse.
- A compact graphite interface, clear fields, grouped CPU/GPU/Windows settings, complete boost choices and German/English text.
- Existing GPU/fan curve policy and history are wired to the new chart, including numeric edits, modifier gestures, fit/zoom and immutable GPU voltage anchors.
- Central persistent settings, separate app versus preset startup, language restart notice, four-zone lighting and native color picker. Closing waits for the app's own control operation; separate cooling helpers are retained.
- Preset names load locally at startup; hardware-backed editor queries are deferred. Manual controls remain separate from bounded telemetry workers.
- Dynamic Boost display now follows the canonical/legacy precedence used by Apply. Existing records are not rewritten on opening; explicit Save uses the existing alias-aware merge.
- Software rendering is the normal default after measuring much lower resident/private memory than the GPU renderer in the UI fixture.
- Normal release builds omit the Slint developer MCP. The standard Slint attribution and license terms are included; original application code remains MIT licensed.

## Verification and limits

See [Validation](../VALIDATION.md) for the final check record. Real interaction tests use an explicitly marked memory-only UI fixture: scroll, resize, minimize/restore, tray restoration, preset switches, exact decimal units, focus/Undo, dropdowns, curve gestures and About/settings behavior. Such tests establish UI behavior, not firmware acceptance.

Hardware contracts, device bindings, readback/restore, startup authorization and recovery journals are unchanged. **This release does not establish fully HP-independent controller ownership or reliable sustained enforcement of an 85 °C limit.** Existing model/BIOS/driver qualifications and outstanding lifecycle tests still apply. Installed protected main/fan/startup executables are not silently replaced by updating the portable dist build.

Slint increases executable size; the user's current priority is responsiveness/correctness and low background resource use. A total tray-idle figure including activated hardware helpers must be measured in that actual configuration, not inferred from the developer fixture.
